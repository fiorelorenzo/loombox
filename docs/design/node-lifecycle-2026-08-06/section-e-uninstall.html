What uninstall removes by default (#814)

You asked for this tonight and it is now filed as #814. The decision worth taking up front is what the default does, because it is the one people click without reading. The footprint on Linux is: the unit and its wants symlink, linger, ~/.loombox/node/ (identity, device token, sessions, mcp secrets, permission policies, agent profiles, spend caps, connected accounts), the keyring entry, ~/.loombox/supervisor/, and ~/.loombox/remote-sessions/ on every ssh target this node ever drove, plus the device registration on the relay, which no local rm -rf can reach.

TodayNo uninstall exists locally; the ssh one keeps files by default

decommission.ts stops and disables the unit and revokes the target, and only deletes files when the caller opts in. Nothing equivalent exists for a local node.

E1-1Default removes the service, keeps the data, always revokes the device

Buys: the safe default. Reinstalling later adopts the existing identity and session history instead of starting a new device. Costs: a machine you meant to wipe still holds session transcripts and secrets until you run the second, explicit step.

E1-2No default: the flow always asks, service or everything

Buys: nobody deletes transcripts by accident and nobody leaves secrets behind by accident. Costs: a question every time, including in the scripted and CI paths, which then need a flag anyway.

E1-3Default removes everything, with a keep-data flag

Buys: "uninstall" means the machine is clean, which is what the word implies and what you asked for tonight. Costs: irreversible by definition; a mis-click destroys local session history that exists nowhere else, since the relay only holds ciphertext it cannot read.
