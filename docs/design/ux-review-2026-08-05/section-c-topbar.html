Today .topbar-actions holds three ghost buttons in this exact order — Workbench, Terminal, Jump to… (+page.svelte:3055-3110) — inside a two-zone justify-content: space-between flex with no centre slot (:4774-4828). Files/Config/Runner live entirely inside the right sidebar's own header as a role="radiogroup" (:3457-3489), the precedent issue #549 set for any mutually-exclusive, always-one-selected control — the same idiom ConfigBar's mode switch uses. The panel's own open/close button carries aria-pressed instead, because unlike a tab, "closed" is a real state, not a missing selection. Both roles are already on two different controls today, but one is nested inside what the other reveals: a screen reader only meets the radiogroup after it has already activated the toggle that shows it. Every option below that puts the tabs in the topbar places both widgets side by side with no reveal dependency between them — cleaner at the ARIA layer, not just visually. Tab selection itself is not persisted: a reload always lands back on Files (:271, :1478) — true of Today and of any option below unless its own opt-why says otherwise.
